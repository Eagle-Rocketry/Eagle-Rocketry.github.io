# Eagle Rocketry Static Website

The supplied Eagle Rocketry logo is included at `assets/logo.png`.

Open `index.html` directly in a browser or host the folder on any static web host.

The project-history copy is based on public Cal State LA pages documenting:
- 2019–2020 Hybrid Rocket Propulsion Unit and Rocketry Aerodynamics & Stability
- 2021 Active Rocket Stabilization & Altitude Control
- 2022 Weight Optimization of Rocket Components Using Filament Winding and Composite Materials
- Cal State LA ECST Makerspace and student competition resources

Internal documentation links currently use `#` placeholders and can be replaced with PDFs, GitHub repositories, Google Drive/SharePoint links, or a `/docs/` directory.
